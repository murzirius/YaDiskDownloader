YaDiskDownloader — запуск через start.cmd

1. Установите обычный Python 3.11 или новее (не free-threaded): https://www.python.org/downloads/windows/
   В установщике включите pip, tkinter и Add Python to PATH.
2. Полностью распакуйте этот архив в отдельную папку.
3. Дважды нажмите start.cmd. При первом запуске нужен интернет:
   программа сама создаст окружение и установит зависимости.
4. Откроется браузер с адресом http://127.0.0.1:8766.
   Нажмите «Как начать» и подключите свой Диск.

Пока работает приложение, оставляйте окно CMD открытым.
Для завершения используйте значок в трее или кнопку выхода в интерфейсе.
При следующих запусках открывайте тот же start.cmd.

Если уже запущена версия EXE, завершите её перед запуском CMD-версии.
Обе версии используют общую историю и профили на этом компьютере.
Токен вводится заново при каждом запуске и не сохраняется на диск.
Обновление CMD-версии: завершите приложение, распакуйте новый CMD-архив
в отдельную папку и откройте start.cmd. История и профили сохраняются.
Встроенная установка обновлений предназначена для версии EXE.
