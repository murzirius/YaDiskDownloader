# YaDiskDownloader 1.2.1 — исправления загрузки и безопасности

## Исправления

- Защищена обработка перенесённых частей: посторонние файлы не обрезаются и не удаляются, жёсткие ссылки не используются для записи.
- Внешний кэш проверок больше не принимается как подтверждение целостности. Для оригиналов с одним MD5 выполняется сверка с источником; превью проверяются декодированием и ограничены по объёму.
- Исправлены повторы после обрыва потока и ошибочная классификация сетевых ошибок как ошибок файловой системы.
- Миниатюры имеют общий срок загрузки. Задержки между повторами не расходуют бюджет следующей попытки; некорректный Retry-After не вызывает бесконечного ожидания.
- Управляющие команды сериализованы. Ошибочные команды не меняют настройки другой задачи; неудачный импорт не оставляет лишних записей и пустых папок.
- Добавлена проверка метаданных API, переносимых путей и некорректных CSRF-заголовков.
- Повреждённые настройки одной задачи или профиля не препятствуют запуску остальной программы. Старые профили нормализуются, число попыток переносится правильно.
- Повреждённые переносимые манифесты пропускаются без срыва импорта.
- Пауза и остановка работают на этапах сравнения обходов и создания отчётов. Убраны зависание опроса интерфейса и отображение устаревших ответов.
- Идентификаторы диагностики связываются только внутри одного архива. В неё включён лимит скорости.
- start.cmd передаёт параметры запуска. Ускорена подготовка больших списков выбранных источников.
- Установщик зависимостей обновляет pip до 26.2.1 перед установкой пакетов.

## Установка и обновление

Windows 10/11 x64: скачайте `YaDiskDownloader-v1.2.1-Windows-x64.zip`, полностью распакуйте и запустите `YaDiskDownloader.exe`. Python не требуется. Сборка не подписана цифровой подписью.

Перед обновлением завершите приложение через трей. История и профили сохраняются; после перезапуска подключите Яндекс.Диск заново. Перенесённые части продолжаются через безопасную копию; исходные части сохраняются на месте и учитываются в объёме папки.

Исходники: `YaDiskDownloader-v1.2.1-source.zip`, Python 3.11+ и `start.cmd`.

Полный список исправлений: `docs/audit-v1.2.1.md` в исходниках.
