# Disk Downloader — скачать Яндекс Диск на компьютер

Бесплатное приложение с локальным интерфейсом на русском языке. Скачивает файлы и превью, сохраняет папки, создаёт ZIP и отчёты. Работает через официальный API Яндекс Диска. Лицензия MIT.

## Быстрый запуск

1. Откройте **[Releases](https://github.com/murzirius/YaDiskDownloader/releases)** и скачайте **YaDiskDownloader-v1.2.1-Windows-x64.zip**.
2. Полностью распакуйте ZIP и запустите **YaDiskDownloader.exe**. Python устанавливать не нужно.
3. В открывшемся браузере следуйте кнопке **«Как начать»**: получите токен Яндекса и подключите Диск.
4. Выберите папки, режим и папку назначения. Нажмите **«Оценить выбранное»**, затем **«Начать»**.

Приложение работает через значок в трее: открыть интерфейс, пауза, продолжение и завершение. Браузер можно закрыть — загрузка продолжится. Для выхода используйте **«Завершить приложение»** в трее или в разделе обновлений и диагностики.

Версия для Windows 10/11 x64. Сборка не подписана цифровой подписью; Windows может показать предупреждение. Все данные и результаты остаются на ПК; скачивайте программу из этого репозитория.

<details><summary>Запуск из исходников</summary>

Установите [Python 3.11 или новее](https://www.python.org/downloads/windows/) с pip и tkinter. Распакуйте исходники и откройте `start.cmd`. При первом запуске зависимости устанавливаются автоматически; нужен интернет. Интерфейс: `http://127.0.0.1:8766`.

</details>

## Получите ключ доступа

Ключ называется **OAuth-токен**. Каждый пользователь получает свой токен для своего аккаунта.

1. Войдите в нужный аккаунт и откройте **[создание приложения Яндекс OAuth](https://oauth.yandex.ru/client/new/)**.
2. Выберите **«Для доступа к API или отладки»**. Укажите название `Disk Downloader` и свою контактную почту.
3. Добавьте только **«Чтение всего Диска» — `cloud_api:disk.read`** и создайте приложение.
4. Скопируйте **ClientID / Client_ID**. В локальном интерфейсе откройте **«Как начать» → второй шаг**, вставьте ClientID и нажмите **«Открыть получение токена»**.
5. На сайте Яндекса подтвердите доступ. Скопируйте токен в поле **OAuth-токен** сверху в приложении и нажмите **«Подключить»**.

Redirect URI задан автоматически: `https://oauth.yandex.ru/verification_code`. `Client_secret` и права записи не нужны. Токен хранится только в памяти и после перезапуска вводится снова. Не публикуйте его на GitHub и не отправляйте другим людям.

Официальная справка: [создание приложения](https://yandex.ru/dev/id/doc/ru/register-api), [получение токена](https://yandex.ru/dev/id/doc/ru/tokens/debug-token).

## Скачайте файлы

1. Отметьте файлы и папки или включите **«Скачать весь Диск»**.
2. Выберите папку на ПК, типы файлов и режим.
3. Нажмите **«Оценить выбранное»** и дождитесь обхода.
4. Нажмите **«Начать»**. Можно поставить на паузу, продолжить или остановить.

| Режим | Результат |
| --- | --- |
| Только превью — по умолчанию | Доступные уменьшенные изображения для фото и видео. Это не полная копия оригиналов. |
| Оригиналы и превью | Полные файлы и доступные превью фото/видео. |
| Оригинал, превью при неудаче | Полный файл; если он недоступен — превью. |

Выберите нужные группы: **фото, видео, музыка, другие файлы**. По умолчанию выбраны все группы. Режим превью применяется к фото и видео; выбранная музыка и другие файлы скачиваются оригиналами. Доступность превью зависит от API Яндекса. Фильтр действует на все страницы и подпапки, оценку объёма и итоговый ZIP.

По умолчанию: **8 потоков · 1 попытка · 20 секунд на попытку**. Для больших файлов на медленном соединении увеличьте время в дополнительных настройках. Число попыток включает первую; оригинал и превью имеют отдельный предел.

В выбранном каталоге создаётся папка **`Disk-…`**. Файлы, отчёты и ZIP сохраняются прямо в ней. Кнопка **«Открыть папку с ZIP»** открывает Проводник, без дополнительного скачивания в «Загрузки».

**ZIP по желанию:** снимите галочку «Создать ZIP после загрузки», чтобы сохранить только файлы, отчёты и журнал. Это экономит место и время упаковки. Позже нажмите «Собрать ZIP» в задании.

**Автопауза:** в дополнительных настройках задайте «Порог заполнения диска, %». По умолчанию — 95%. Учитывается весь диск, на котором находится папка назначения, включая другие файлы на нём. При достижении порога задание встаёт на паузу. Освободите место и нажмите «Продолжить»; порог можно изменить и во время паузы. Время паузы не расходует лимит попытки.


**Продолжение после обрыва:** оригиналы сохраняются частями `.disk-….part` в папке импорта. При повторе проверяются источник и контрольная сумма части. Если сервер подтверждает продолжение, загружаются оставшиеся байты; иначе файл скачивается заново. Итоговый оригинал проверяется целиком. Для превью продолжение возможно только при подтверждённой идентичности ответа сервера. Части занимают место и не входят в ZIP результатов. Для продолжения на другом ПК перенесите всю папку импорта вместе с частями и `.disk-import*.sqlite3`.

**Повтор отдельных файлов:** откройте «Ошибки», нажмите «Повторить этот файл» или отметьте несколько записей и нажмите «Повторить выбранные». Выбор сохраняется при переходе между страницами ошибок.

**Профили:** раскройте «Профили настроек», введите название и нажмите «Сохранить профиль». Профиль хранит выбранные источники, папку назначения и параметры. Чтобы использовать его, выберите профиль и нажмите «Применить». Токен в профиль не входит.

**Обновления и диагностика:** нажмите кнопку версии в верхней панели. При открытии приложения автоматически проверяется последний публичный релиз [murzirius/YaDiskDownloader](https://github.com/murzirius/YaDiskDownloader). При наличии новой версии появляется ссылка на релиз. Автоматическую проверку можно выключить; доступна ручная проверка. Запрос к GitHub не содержит токена Яндекса.

Для диагностики выберите задание в истории, откройте окно версии и нажмите «Посмотреть состав», затем «Сохранить ZIP диагностики». Архив сохраняется в папке импорта и открывается Проводник. В нём версия программы и системы, параметры, статистика, до 1000 ошибок и 2000 последних событий с обезличенными идентификаторами источников. Имена, пути, ключи, временные ссылки, содержимое файлов и база данных не включаются. Отправку архива выполняете вы сами.

Статистика показывает объём результатов на ПК и свободное место. ZIP — отдельная копия файлов и тоже занимает место. **100% означает обработку очереди**, включая ошибки; проверьте итоговый статус.

**Оставшееся время** показывается приблизительно после накопления данных о скорости. Если размеры известны, используется скорость передачи; для неизвестных размеров — скорость обработки файлов. На паузе оценка не отсчитывается. Во время скачивания оценивается загрузка, во время упаковки — ZIP. Скорость сети, повторы и размер следующих файлов могут менять оценку.

**Если пропал интернет:** при сетевом обрыве появляется предупреждение о потере связи с Диском. Программа сохраняет части файлов и ждёт восстановления доступа. После восстановления открывает новые соединения и продолжает автоматически; ожидание связи не расходует попытки. HTTP 403/404 и другие ответы сервера обрабатываются отдельно.

## Посмотрите журнал

В папке `Disk-…` автоматически появляется отдельный **`log-….html`**. Откройте его двойным щелчком или кнопкой **«Подробности задания → Открыть HTML-журнал»**. Он работает в браузере без интернета.

Журнал обновляется **каждые 5 минут** во время обхода, скачивания и создания ZIP, в том числе на паузе. Также сохраняется сразу при начале и завершении операции, остановке или ошибке. Это один обновляемый файл; при продолжении того же задания новые события добавляются к прежней истории. Новый импорт или дозагрузка создаёт свой журнал.

События разделены по группам: задание, обход диска, оригиналы, превью, уже скачанное, ошибки и повторы, отчёты и ZIP. Есть поиск по пути и тексту, фильтр уровня и страницы по 50 событий. В файл сохраняется вся история. Чтобы увидеть последнее сохранение в открытой вкладке, обновите страницу.

Журнал сохраняется независимо от выбранных форматов отчёта и **не включается в ZIP результатов**. Ключи доступа и временные ссылки скрываются. Имена и пути файлов остаются в журнале — учитывайте это, если передаёте его другим людям.

## Дозагрузите недостающее

Выберите **«Как загрузить → Дозагрузить недостающее»**, укажите **саму прежнюю папку `Disk-…`**, нажмите **«Оценить выбранное»**, затем **«Начать»**.

Программа заново обойдёт Диск и проверит локальные копии. Сначала обрабатываются файлы без результата, затем программа пробует скачать оригиналы для файлов только с превью. Если оригинал недоступен, проверенное превью остаётся результатом. Актуальный оригинал исключает новую загрузку превью. При дозагрузке это правило действует независимо от выбранного режима.

Существующие файлы не удаляются и не перезаписываются. Для изменившихся или повреждённых копий создаётся новый файл. Если выбор не задан заново, исходные пути берутся из предыдущего импорта.

При переносе результатов копируйте **всю папку**, включая `.disk-import*.sqlite3`: там хранятся имена и контрольные суммы, без токена.

## Если что-то не получается

| Проблема | Решение |
| --- | --- |
| Python не найден | Установите Python и снова откройте `start.cmd`. |
| Браузер не открылся | Откройте http://127.0.0.1:8766 вручную. |
| Порт занят | В PowerShell из папки проекта: `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 --port 8767`. |
| Токен не подходит | Проверьте аккаунт и право `cloud_api:disk.read`, получите токен заново. |
| Файл не успевает скачаться | Увеличьте лимит попытки и повторите неудачные. Чтобы поменять ограничения живого задания, остановите его и продолжите. |
| Нет превью | Яндекс выдаёт превью не для всех файлов; выберите режим с оригиналом. |
| Оценка больше занятого места в облаке | Чужие общие папки и фото из безлимита включаются в скачивание, хотя могут не расходовать квоту. Выберите только нужные папки. |
| Загрузка прервалась | Подключите Диск, выберите задание в истории и нажмите «Продолжить». |


## Управление загрузкой

| Возможность | Как использовать |
| --- | --- |
| Исключения | Раскройте «Исключения папок и файлов»: один путь или шаблон на строку. Например `disk:/Фото/Черновики` или `*.tmp`. Кнопка ⊖ в списке исключает объект. |
| Объём по папкам | После оценки нажмите «Объём по папкам». Внутри можно открывать папки и видеть число файлов и объём оригиналов; неизвестные размеры отмечены отдельно. |
| Отчёт об изменениях | При дозагрузке нажмите «Изменения». Программа сравнит источники с прошлым импортом. После загрузки появится `changes-N.html`. Локальные файлы не удаляются. |
| Ограничение скорости | Дополнительные настройки → «Общая скорость, МиБ/с». Лимит общий для всех потоков; 0 — без ограничения. |
| Сообщение об ошибке | Обновления и диагностика → «Сообщить об ошибке». Проверьте готовый текст, откройте форму GitHub и отправьте её. ZIP диагностики можно приложить вручную. |

При обновлении завершите приложение через трей, замените EXE и запустите снова. История и профили сохраняются в `%LOCALAPPDATA%\YaDiskDownloader`; токен нужно ввести заново. Результаты остаются в выбранной папке.


## Обновление и дозагрузка

История и профили обеих версий хранятся в `%LOCALAPPDATA%\YaDiskDownloader`. При переходе со старых исходников завершите прежний экземпляр и обновите файлы в прежней папке либо распакуйте новую версию рядом. Задачи из `.state` переносятся автоматически; прежняя база сохраняется. Дальнейшее обновление EXE или исходников сохраняет общую историю независимо от новой папки распаковки. Токен после перезапуска вводится заново.

При дозагрузке «Ранее сохранено» показывает прежние результаты. Подтверждённые оригиналы учитываются до старта и исключаются из оставшегося объёма. Прежние превью остаются результатами, пока программа пробует получить оригиналы. Неудача одного варианта не считается ошибкой при успешно сохранённом другом; подробности сохраняются в журнале. Ошибки файловой системы и обработки остаются видимыми.

«Объём папки на ПК» включает прежние файлы, отчёты, ZIP и недокачанные части; обновляется в фоне примерно каждые 10 секунд. Умные потоки временно отключены: используется число потоков, заданное в дополнительных настройках.
