# YaDiskDownloader 1.4.0

Удобнее проверять папку, выбирать качество дозагрузки и управлять заданиями.

## Что изменилось

- Перед скачиванием показан план: готовые оригиналы, файлы только с превью, отсутствующие копии и оставшаяся работа.
- Для дозагрузки доступны три варианта: получить оригиналы, считать превью достаточным результатом или сохранить обе копии.
- После успешного получения и проверки оригинала прежнее превью удаляется, если режим двух копий выключен. Изменённые и занятые файлы сохраняются.
- Журналы и отчёты не входят в проверку скачанного содержимого. Для них сохраняются только резервы имён без обращения к самим файлам. История и опись по-прежнему читаются для определения сохранённых результатов.
- Можно выбрать быструю или полную проверку. Быстрая использует прежний результат проверки только при подтверждённом отсутствии изменений файла; полная перечитывает содержимое.
- В карточке задания объясняется текущий этап и причина ожидания. После завершения показаны новые оригиналы, новые превью и уже сохранённые результаты.
- Добавлен поиск по всем файлам задания с фильтрами состояния, открытием расположения файла и повторной загрузкой.
- Одинаковые ошибки объединены по причинам с доступными действиями.
- Исключения можно добавлять из списка файлов и отменять отдельными кнопками.
- Доступность папки назначения проверяется в фоне. При отличии исходного выбора от прежней загрузки появляется предупреждение.
- Добавлена защита от точных дубликатов: одинаковые оригиналы с подтверждённым содержимым скачиваются один раз. Защита выключена по умолчанию. Найденные лишние копии показываются в списке «Дубликаты» и автоматически не удаляются. Для переноса в корзину нужно отдельно выбрать копии и подтвердить действие; совпадение имени, размера или даты не приводит к удалению.
- История, отчёты и дозагрузка учитывают общую копию; в ZIP она включается один раз. Если корзина недоступна, копия остаётся на месте.
- Windows EXE открывает собственное окно с этапами запуска, подключением ключа и управлением сохранёнными заданиями. Окно оформлено в тёмной теме с отдельными блоками состояния, прогресса и управления. Создание заданий доступно в веб-интерфейсе по отдельной кнопке.
- Добавлены тёмная, светлая, лесная и сливовая темы. Свои темы можно устанавливать из JSON-файлов с цветами; скрипты и произвольный CSS не принимаются.
- Доступно до 20 одновременных загрузок. По умолчанию остаются 8 потоков, 1 попытка и 20 секунд ожидания без данных.

## Что скачать (одно из двух)

- **YaDiskDownloader-v1.4.0-Windows-x64.zip** — готовое приложение Windows 10/11 x64. Распакуйте архив и откройте `YaDiskDownloader.exe`. Python не нужен.
- **YaDiskDownloader-v1.4.0-Windows-CMD.zip** — запуск через `start.cmd` с установленным Python 3.11 или новее.

Перед обновлением остановите работу, дождитесь остановки и завершите приложение через «Выход». Распакуйте новую версию в отдельную папку. Для дозагрузки выберите прежнюю папку результатов. Ключ после полного выхода подключается снова.

Скорость зависит от Яндекс.Диска, интернета и накопителя. При ограничениях сервиса увеличение потоков может не помочь. Если возникла ошибка, [сообщите о ней](https://github.com/murzirius/YaDiskDownloader/issues/new).
