# YaDiskDownloader 1.5.0

> **Предварительная версия (Pre-release).** Предназначена для тестирования новых возможностей. Стабильная версия остаётся доступна отдельно.

## Сборка 20261025.1

- Размеры и скорость показаны привычными обозначениями: КБ, МБ, ГБ и ТБ. Числовые значения и ограничения сохранены.
- Исправлены соприкасающиеся кнопки в инструментах, оформлении, проверке приложения и списке файлов задания.
- Длинные названия и увеличенный текст больше не растягивают панели за экран. Исправлены вкладки, поля параметров, статистика и перенос подписей.

Проверены 576 вариантов экранов в Edge и Chrome, включая ширину 320–1920 пикселей, текст 100% и 130%, светлую тему и компактный режим. Локально прошли 139 регрессионных тестов, один пропущен. Windows EXE пересобран и запущен; нативное окно macOS локально не проверялось.

- Укреплены установка и откат обновления Windows, работа с длинными путями и безопасная очистка старых обновлений.
- Исправлены ограничение скорости в тихие часы, настройки уведомлений и повторный запуск проверки приложения.

- Исправлена повторная постановка одного файла в несколько потоков после сбоя накопителя, вызывавшая ложные ошибки сохранения.
- При недоступной папке отложена запись HTML-журнала и переносимой описи; прогресс остаётся в базе приложения.

## Обход и продолжение загрузки

- **Быстрее обход больших папок:** до четырёх страниц одной папки запрашиваются одновременно. Сохранение страниц и позиции обхода остаётся последовательным.
- **Продолжение после перезапуска:** незавершённая дозагрузка в ту же папку с прежними фильтрами использует сохранённый результат обхода. Уже подтверждённые страницы не нужно читать заново. Для поиска новых и изменённых файлов доступен повторный обход.
- **Этапы идут друг за другом:** по умолчанию после проверки начинается скачивание, затем подготовка результатов. Галочка «После проверки сразу скачивать» позволяет оставить только подготовку плана. Очередь и заданное время запуска учитываются.
- **Защита свободного места:** при остатке меньше 500 МБ новые файлы не запускаются, даже если обычная автопауза выключена. Текущие передачи завершаются только при известном небольшом остатке, который помещается с резервом; иначе сохраняются части и включается пауза. Для продолжения освободите минимум 1 ГБ и выполните выбранное ограничение заполнения диска.
- Исправлено продолжение после освобождения места: две быстрые проверки накопителя больше не могут принять свежий результат за старый из-за точности системных часов.
- **Быстрее проверка готовых файлов на медленном накопителе:** до четырёх параллельных чтений сведений о файлах. Проверки целостности и защита от перезаписи сохранены.

В изолированном сравнении обход 55 000 файлов с задержкой API 100 мс сократился с 7,86 до 3,84 с, проверка 1000 готовых файлов с задержкой накопителя — с 8,64 до 2,69 с. Это модельные измерения: скорость настоящего Яндекс.Диска и сетевой папки зависит от их состояния. [Методика, результаты и ограничения проверки](https://github.com/murzirius/YaDiskDownloader/blob/main/docs/scan-pipeline-validation.md).


Обновление обхода и интерфейса. Для Windows и macOS доступны готовые приложения; CLI поддерживается только в Linux.

## Основное

- Обход читает до четырёх страниц папок одновременно, включая страницы одной большой папки и запрашивает до 1000 объектов на страницу. Сохранение прогресса остаётся последовательным. Повторяющаяся страница API останавливает проблемную папку с объяснением вместо бесконечного обхода.
- Подготовка локальных имён выполняет меньше запросов к SQLite и сохраняет защиту от совпадений и перезаписи чужих файлов.
- **«Посчитать папки»** в фоне рассчитывает объём вложенных файлов и дату последнего изменённого файла. Дата самой папки больше не выдаётся за дату её содержимого. Неизвестные и неполные итоги обозначены отдельно; подсчёт можно остановить.
- Добавлены SVG-иконки типов файлов и выравнивание элементов интерфейса.
- Новые темы: Really Black, Dracula, Nord, Catppuccin Mocha и Latte, Tokyo Night, Everforest, Solarized Light и Dark, Gruvbox и High Contrast. Доступны акцентный цвет, размер текста и переключение вслед за системой.
- Простой режим скрывает дополнительные параметры; компактный список уменьшает высоту строк.
- Добавлены фильтр дат, приоритетные папки, изменение потоков и скорости во время работы.
- Расписание очереди, тихие часы и опциональная защита от автоматического сна устройства. Для расписания приложение должно быть запущено, а ключ подключён.
- В поиске файлов показаны причины пропусков. Добавлены проверка приложения, график передачи данных и повторный обход для поиска новых и изменённых файлов.

## Windows, macOS и Linux

- **Windows:** готовое приложение EXE с мини-окном и треем. Python и CMD не нужны. Установка обновления из интерфейса остаётся функцией Windows.
- **macOS:** приложение из DMG для Apple Silicon или Intel. Запуск — из «Программ», управление заданиями — в браузере. CLI в приложение не входит.
- **Linux:** браузерный интерфейс и CLI. Фоновый запуск позволяет закрыть терминал и снова подключиться к состоянию задания. Доступны создание загрузок, пауза, продолжение, очередь и безопасный выход. [Установка и команды](https://github.com/murzirius/YaDiskDownloader/blob/main/docs/cli.md).

Ключ хранится только в памяти приложения; после полного выхода его нужно подключить заново. Закрытие терминала и выход из учётной записи ОС имеют разное поведение.

[Описание функций](https://github.com/murzirius/YaDiskDownloader/blob/main/docs/features-v1.5.0.md)

## Безопасность и сохранность

- Pillow обновлена до 13.0.0. Декодирование превью ограничено поддерживаемыми форматами до открытия изображения.
- Исправлены проверки создания системного окна выбора папки Windows перед обращением к COM-объектам.
- Локальные имена учитывают ограничения длины UTF-8 и UTF-16 и нормализацию Unicode.
- Исправлен порядок прерывания сетевого чтения на macOS после обрыва связи: загрузка не должна ждать прежнего таймаута закрытого соединения.
- Проверка целостности, докачка частей, защита путей, резервные копии и ручное подтверждение очистки сохранены.

Скорость зависит от Яндекс.Диска, сети и накопителя. Увеличение числа запросов не обходит ограничения Яндекса. Если часть папки недоступна, программа сообщает о неполном результате.

Результаты проверок публикуются в [GitHub Actions](https://github.com/murzirius/YaDiskDownloader/actions). Длительная загрузка из реального аккаунта Яндекса в эти проверки не входит. [Измерения и границы проверки](https://github.com/murzirius/YaDiskDownloader/blob/main/docs/validation-v1.5.0.md).

## Установка на macOS

Выберите установщик для своего Mac:

- [**YaDiskDownloader-v1.5.0-macOS-arm64.dmg**](https://github.com/murzirius/YaDiskDownloader/releases/download/v1.5.0-build.20261025.1/YaDiskDownloader-v1.5.0-macOS-arm64.dmg) — Apple Silicon: M1, M2, M3, M4 и новее.
- [**YaDiskDownloader-v1.5.0-macOS-x64.dmg**](https://github.com/murzirius/YaDiskDownloader/releases/download/v1.5.0-build.20261025.1/YaDiskDownloader-v1.5.0-macOS-x64.dmg) — Mac с процессором Intel.

Процессор указан в меню ** → Об этом Mac**. Требуется macOS 13 или новее; сборки проверены на macOS 15.

Откройте DMG, перетащите **YaDiskDownloader** в **Applications («Программы»)**, извлеките образ и откройте приложение из «Программ». Python и терминал не нужны. В небольшом окне показан запуск; доступны кнопки **«Открыть интерфейс»** и **«Выход»**. Закрытие окна и браузера не останавливает загрузки. Для завершения нажмите **«Выход»** или **⌘Q**: приложение дождётся сохранения прогресса.

Предварительная сборка **не заверена Apple**. Если Gatekeeper блокирует запуск, разрешите открытие приложения в **«Системные настройки → Конфиденциальность и безопасность»**, только если доверяете источнику. Отключать защиту macOS целиком не нужно. [Инструкция Apple](https://support.apple.com/ru-ru/102445).

Оба установщика прошли [проверку установки, запуска и выхода на macOS](https://github.com/murzirius/YaDiskDownloader/actions/workflows/macos-installer.yml). [Подробная инструкция и сведения о сборке](https://github.com/murzirius/YaDiskDownloader/blob/main/docs/macos.md).
