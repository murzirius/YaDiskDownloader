# YaDiskDownloader 1.5.0

Обновление обхода, интерфейса и управления из терминала. Добавлена работа общего браузерного интерфейса и CLI на Windows, macOS и Linux.

## Основное

- Обход читает до четырёх независимых страниц папок одновременно и запрашивает до 1000 объектов на страницу. Сохранение прогресса остаётся последовательным. Повторяющаяся страница API останавливает проблемную папку с объяснением вместо бесконечного обхода.
- Подготовка локальных имён выполняет меньше запросов к SQLite и сохраняет защиту от совпадений и перезаписи чужих файлов.
- **«Посчитать папки»** в фоне рассчитывает объём вложенных файлов и дату последнего изменённого файла. Дата самой папки больше не выдаётся за дату её содержимого. Неизвестные и неполные итоги обозначены отдельно; подсчёт можно остановить.
- Добавлены SVG-иконки типов файлов и выравнивание элементов интерфейса.
- Новые темы: Really Black, Dracula, Nord, Catppuccin Mocha и Latte, Tokyo Night, Everforest, Solarized Light и Dark, Gruvbox и High Contrast. Доступны акцентный цвет, размер текста и переключение вслед за системой.
- Простой режим скрывает дополнительные параметры; компактный список уменьшает высоту строк.
- Добавлены фильтр дат, приоритетные папки, изменение потоков и скорости во время работы.
- Расписание очереди, тихие часы и опциональная защита от автоматического сна устройства. Для расписания приложение должно быть запущено, а ключ подключён.
- В поиске файлов показаны причины пропусков. Добавлены проверка приложения, график передачи данных и повторный обход для поиска новых и изменённых файлов.

## CLI и другие ОС

Фоновый запуск позволяет закрыть терминал и снова подключиться к состоянию задания. CLI поддерживает создание загрузок, план, паузу, продолжение, повтор, ограничения и безопасный выход. Ключ вводится скрыто и хранится только в памяти приложения.

В macOS и Linux используются системные папки истории и платформенные команды открытия результатов. На Linux для графического выбора папки нужен `zenity` или `kdialog`; без графического сеанса путь можно ввести вручную.

Windows-мини-окно и трей сохранены. Автоматическая установка обновления EXE остаётся функцией Windows. После перезапуска приложения требуется подключить ключ заново; закрытие терминала и выход из учётной записи ОС имеют разное поведение.

## Безопасность и сохранность

- Pillow обновлена до 13.0.0. Декодирование превью ограничено поддерживаемыми форматами до открытия изображения.
- Исправлены проверки создания системного окна выбора папки Windows перед обращением к COM-объектам.
- Локальные имена учитывают ограничения длины UTF-8 и UTF-16 и нормализацию Unicode.
- Проверка целостности, докачка частей, защита путей, резервные копии и ручное подтверждение очистки сохранены.

Скорость зависит от Яндекс.Диска, сети и накопителя. Увеличение числа запросов не обходит ограничения Яндекса. Если часть папки недоступна, программа сообщает о неполном результате.

## Что скачать (одно из двух)

- **YaDiskDownloader-v1.5.0-Windows-x64.zip** — готовое приложение Windows 10/11 x64 с мини-окном, треем и отдельным консольным приложением. Распакуйте и откройте `YaDiskDownloader.exe`. Python не нужен.
- **YaDiskDownloader-v1.5.0-Windows-CMD.zip** — запуск через `start.cmd`; требуется Python 3.11 или новее. Для фонового управления предусмотрен `yadisk.cmd`.

Перед заменой версии остановите задание, дождитесь остановки и нажмите «Выход». Распакуйте новую версию отдельно. Историю, переносимую опись и скачанные файлы не удаляйте. Для дозагрузки укажите прежнюю папку результатов.

Если возникла проблема, нажмите **«Диагностика»** и приложите архив к [сообщению об ошибке](https://github.com/murzirius/YaDiskDownloader/issues/new). Ключ доступа публиковать не нужно.
