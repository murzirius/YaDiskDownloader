# Исправления и удобство в 1.3.8

| Проблема | Что исправлено |
|---|---|
| Ошибка получения метаданных убирала готовый файл из учёта | Запись результата сохраняется вместе с файлом |
| Офлайн-проверка пропускала ни разу не скачанные файлы | Проверяется вся сохранённая опись |
| Большой список проблем обрезался | Результаты хранятся в SQLite и выдаются страницами |
| Дозагрузка могла зависеть от открытой страницы проблем | Используется весь проверенный выбор |
| Ошибка сохранения описи скрывалась | Есть понятная ошибка и повторное сохранение без ключа |
| Старые ошибки обхода оставались после успешного повтора | Ошибки в успешно проверенном участке обновляются |
| Поиск истории не учитывал регистр русских букв | Используется Unicode casefold |
| Очередь повторно запускала вручную начатое задание | Состояния ручного запуска и очереди согласованы |
| Заблокированное задание очереди было сложно продолжить | Добавлено явное повторение |
| Недоступная папка показывала нулевой размер | Отображается причина и неизвестный размер |
| Размер сохранял объём вручную удалённых файлов | Обновление использует реальную папку |
| Итоговый объём мог не обновиться после ZIP | Добавлена фоновая итоговая сверка с сохранением запроса обновления |
| Проверка готовых файлов открывала тысячи соединений | Один рабочий контекст, порции по 200 записей, без перезаписи неизменившихся отметок |
| Приоритеты и наследование истории расходовали память и блокировали действия | Ограниченные порции, фоновая подготовка и возобновление после остановки |
| Восстановление после сбоя задерживало HTTP | Фоновое восстановление с видимым этапом и защитой от конфликтующих команд |
| Длинные локальные операции плохо реагировали на остановку | Контроль отмены в хешировании и экспортах |
| Фоновая запись могла пережить финальное сохранение | Ожидание писателя, отмена перед публикацией новой описи |
| Счётчики предыдущего этапа выглядели как окончательный результат | Явное ожидание статистики при смене этапа |
| Список ошибок сбрасывал фокус | Обновление только изменившегося списка, сохранение выбора |
| Новая загрузка наследовала настройки открытой истории | Явный сброс настроек нового задания |

Главный экран содержит четыре понятных действия. Настройка загрузки разделена на выбор файлов, папку на ПК и качество. Перед запуском показываются итог и проверка возможности записи; сложные параметры свёрнуты. Добавлены подсказки, доступный клавиатурный фокус и объяснения учёта превью. Обновление журнала и описи доступно без ключа Яндекса.

Методика, результаты измерений и ограничения: [проверки производительности](performance-v1.3.8.md). Наличие этих проверок не означает отсутствия любых возможных ошибок.
