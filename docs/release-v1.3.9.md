# YaDiskDownloader 1.3.9

Исправления стабильности и понятная подготовка дозагрузки. Чтение прежней истории теперь показывает конечный прогресс и больше не выглядит как бесконечный поиск файлов.

## Что изменилось

- При чтении истории показаны количество записей из общего числа, процент и текущий этап. Записи истории отделены от количества файлов; подготовку можно остановить и продолжить.
- Исправлено ожидание DNS: лимит попытки и остановка работают до подключения к серверу. Для TCP и TLS учитывается оставшееся время; проверка сертификатов сохранена.
- ZIP, опись и журнал после паузы можно продолжать без ключа Яндекса, когда операция работает только с локальными данными.
- Исправлены конфликты и чрезмерное удлинение имён, повторная загрузка при различном регистре контрольной суммы и отмена во время проверки результатов.
- Исправлены состояния занятости после ошибок фоновых потоков, выбора папки, офлайн-проверки и проверки обновлений.
- Улучшена обработка повреждённых настроек и переноса старой истории.
- При ошибке пересборки сохраняется ссылка на прежний готовый ZIP. Готовые архивы сбрасываются на накопитель перед публикацией.
- Исправлена очистка временных файлов и их учёта, в том числе при ошибках записи SQLite во время упаковки. Сохранные части для докачки остаются.

## Что скачать (одно из двух)

- **YaDiskDownloader-v1.3.9-Windows-x64.zip** — готовое приложение для Windows 10/11 x64. Распакуйте архив и откройте `YaDiskDownloader.exe`. Python не нужен.
- **YaDiskDownloader-v1.3.9-Windows-CMD.zip** — запуск через `start.cmd`. Нужен Python 3.11 или новее.

Перед обновлением остановите задание, дождитесь остановки и завершите приложение через «Выход». Распакуйте новую версию в отдельную папку. История и профили сохраняются; для дозагрузки выберите прежнюю папку результатов. После полного выхода ключ Яндекса нужно подключить снова.

Сбои Яндекс.Диска и доступ к сетевому хранилищу могут влиять на скорость. Проверки на тестовых данных не заменяют работу с конкретным аккаунтом, NAS или восстановление после отключения питания. Если возникла проблема, [сообщите об ошибке](https://github.com/murzirius/YaDiskDownloader/issues/new).
