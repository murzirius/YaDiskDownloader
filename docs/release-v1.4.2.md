# YaDiskDownloader 1.4.2

Понятнее проверка папки, безопаснее продолжение после потери накопителя и быстрее работа большой истории.

## Что изменилось

- При недоступности папки назначения или NAS работа приостанавливается с объяснением. Для продолжения проверяется доступность той же папки. Временная потеря связи не удаляет запись о скачанном файле из описи.
- Проверки накопителя выполняются отдельно от обработки интерфейса, с ограниченным временем ожидания и числом фоновых проверок.
- При длительном отсутствии прогресса появляется предупреждение. Плановые ожидания Яндекс.Диска, ограничение скорости и обычная пауза не считаются зависанием.
- При проверке папки отдельно показаны проверенные и оставшиеся файлы, оригиналы и превью. Добавлена оценка времени; при недостатке данных и долгом чтении она уточняется.
- После завершения доступны понятные действия: повторить ошибки, подготовить получение оригиналов вместо превью, открыть результаты. Повтор ошибок файлов не запускает улучшение успешно сохранённых превью.
- Повторный запуск EXE возвращает существующее окно программы с той же историей и портом.
- Ускорено сохранение большого HTML-журнала. Поиск выполняется частями и отменяет устаревший запрос, если введён новый. История сохраняется полностью в одном файле.
- Улучшены значки для высокого DPI. Добавлены автоматические проверки размеров окна при 100/150/200% и повторного запуска готового EXE.
- Исправлены восстановление после ошибки запуска рабочего потока, отображение проверки при паузе загрузки и совместимость проверки MD5 API с ограничениями FIPS. Проверка SHA-256 сохранена.
- Исправлен запуск после аварийного завершения на Windows: база восстанавливается средствами SQLite до создания резервной копии перед обновлением. Временная ошибка доступа повторяется с коротким ограниченным ожиданием; постоянная ошибка не скрывается.
- Проверка папки сообщает об отключённом накопителе и неожиданных ошибках, не выдавая незавершённую проверку за успешную.

## Что скачать (одно из двух)

- **YaDiskDownloader-v1.4.2-Windows-x64.zip** — готовое приложение Windows 10/11 x64. Распакуйте и откройте `YaDiskDownloader.exe`. Python не нужен.
- **YaDiskDownloader-v1.4.2-Windows-CMD.zip** — запуск через `start.cmd` с установленным Python 3.11 или новее.

Перед обновлением остановите работу, дождитесь остановки и завершите программу через «Выход». Распакуйте новую версию в отдельную папку. Для дозагрузки выберите прежнюю папку результатов. После полного выхода подключите ключ снова.

Если возникла ошибка, [сообщите о ней](https://github.com/murzirius/YaDiskDownloader/issues/new).
