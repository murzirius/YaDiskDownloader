## Проверки v1.2.0

Проверены ожидание сети при одном разрешённом запросе, сохранение и продолжение части через Range, восстановление страницы обхода, ограничения попыток и времени, сохранение ручной паузы и остановка без интернета. HTTP 401/403/404/429/503 не вызывают предупреждение о потере сети. Служебные проверки доступности выполняются без токена.

На локальном HTTP-сервере одновременно передаются два файла: один оставляет открытое зависшее соединение, другой вызывает обрыв. После восстановления оба результата получены за менее чем три секунды без ожидания прежнего 20-секундного таймаута; содержимое сверено с источниками. Время ожидания сети исключается из статистики скорости и ETA.

В браузере проверены видимость предупреждения при обрыве, его исчезновение после восстановления и завершение без ошибок консоли. Готовый Windows EXE проверен на загрузку статики, работу трея, профилей, сборку ZIP без сети и штатное завершение. Обновление общей папки состояния сохраняет прежнюю историю без повторного переноса задач.
