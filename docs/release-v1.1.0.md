# YaDiskDownloader 1.1.0

Добавлено:

- ZIP результатов по желанию: можно сохранить файлы и отчёты, а архив собрать позднее.
- Автопауза по заданному проценту заполнения диска назначения. Начальный порог — 95%.
- Сохранение недокачанных частей и продолжение с места обрыва, когда сервер поддерживает его.
- Повтор конкретного файла или отмеченных файлов из списка ошибок.
- Умное управление количеством потоков с учётом ошибок и скорости.
- Сохранение и применение профилей настроек без токенов.
- Автоматическая и ручная проверка новых релизов на GitHub.
- Предварительный просмотр и сохранение обезличенной диагностики в ZIP.

Запуск на Windows:

1. Установите Python 3.11 или новее.
2. Скачайте прикреплённый `disk-downloader.zip` и полностью распакуйте его.
3. Откройте `start.cmd` и дождитесь установки зависимостей.
4. Следуйте инструкции в веб-интерфейсе.

При обновлении существующей установки сохраните свою папку `.state` и все папки результатов. Обновляйте исходники при остановленном приложении. Для работы на другом ПК переносите папку импорта полностью, включая `.disk-import*.sqlite3` и `.part`.

Продолжение загрузки зависит от сервера. При отсутствии поддержки программа скачивает файл заново. Подробности использования — в README.md.
