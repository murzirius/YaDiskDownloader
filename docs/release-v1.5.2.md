# YaDiskDownloader 1.5.2

## Установщик для Windows

- Вместе с ZIP публикуется `YaDiskDownloader-v1.5.2-Windows-x64-Setup.exe`: установка для текущего пользователя без прав администратора, ярлык в меню «Пуск», ярлык на рабочем столе по желанию, запуск после установки.
- Setup.exe поверх прежней установки обновляет программу; история и настройки не затрагиваются.
- При удалении программа спрашивает, удалять ли историю и настройки (по умолчанию нет). Скачанные файлы не удаляются никогда.
- Установщик и EXE не подписаны цифровой подписью: Windows SmartScreen может показать предупреждение, нажмите «Подробнее» → «Выполнить в любом случае».
- Обновление из окна версии работает как прежде и использует ZIP; имя и состав ZIP не изменились.

Подробнее: [установщик для Windows](https://github.com/murzirius/YaDiskDownloader/blob/main/docs/windows-installer.md).
