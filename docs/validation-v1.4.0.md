# Проверки YaDiskDownloader 1.4.0

Среда: Windows x64, Python 3.14.8, SQLite 3.51.3. Проверки используют временные файлы и тестовый API.

## Корректность

- Полный набор: **448 passed, 1 skipped за 216,50 с**. Пропуск связан с правами Windows на символические ссылки.
- Защита от дубликатов: 20 регрессионных сценариев, включая 20 потоков, разные файлы с одинаковым именем, повреждённую копию, перенос в настоящую корзину Windows, недоступную корзину, повторную дозагрузку, общий файл в ZIP, миграцию старой схемы базы, восстановление прерванного переноса и сохранение изменённых файлов.
- Отдельно проверены обновление превью до оригинала, сохранение изменённых файлов, повторная проверка оригинала перед удалением превью, режим двух копий, повторное использование результатов, поиск и страницы списка файлов, 20 потоков, защита новых HTTP-команд и проверка папки в фоне.
- Проверены конфликты скачанных файлов со служебным `report.json`: служебные имена остаются зарезервированными без чтения самих журналов и отчётов.
- JavaScript проходит синтаксическую проверку. Проверки тем отклоняют исполняемые стили, URL вместо цветов, неизвестные поля и нечитаемый текст.

## Перенос истории

Три прогона, медиана. Синтетические метаданные: 2000 скачанных файлов и 6000 служебных резервов имён. База сравнения — версия 1.3.9, коммит `752959c`. Проверено сохранение всех записей файлов, проверок и резервов имён.

| Показатель | До | После |
|---|---:|---:|
| Время переноса | 12,6901 с | 9,0019 с |
| Время CPU процесса | 12,5469 с | 8,7031 с |
| Обращения к проверке путей служебных записей | 6000 | 0 |

Выигрыш по времени — около 29%. Это проверка переноса метаданных, а не скорости чтения содержимого или работы NAS. RSS и физический дисковый ввод-вывод в этом опыте отдельно не измерялись. Повторение: `python tools/benchmark_import.py --baseline-ref 752959c --runs 3`.

## Windows EXE

Настоящий EXE запущен с отдельной тестовой папкой состояния. Проверены версия 1.4.0, сборка 20261018.8, SQLite, актуальность встроенных файлов интерфейса, история прерванной работы, ожидание очереди, выбор папки, CSRF, выход через HTTP и нативное закрытие трея. Дочерние процессы завершились, порт и блокировка состояния освободились.

На этом EXE отдельно выполнен перенос истории 1000 тестовых файлов: конечный предел 3002 записи, опись сохранена, контрольные суммы всех файлов совпали. Время вместе с запуском — 5,311 с.

Окно управления Windows EXE запущено и визуально проверено на сборке 20261018.7; модуль окна в 20261018.8 не изменён: тёмные блоки состояния, прогресс и кнопки управления, отсутствие создания заданий. Обновление состояния и кнопка выхода проверены на промежуточной сборке с тем же кодом окна. В финальной сборке подтверждён выход через HTTP и трей; повторное нажатие кнопки окна не завершено из-за ограничения автоматизации активации окна. Подключение реального аккаунта через окно не проверено.

Защита от дубликатов изначально выключена. Обход формирует список без удаления; перенос выбранных копий запускается отдельной командой с подтверждением. Список, выбор одной копии, подтверждение и отмена вручную проверены в браузере с тестовым API. Отдельно пройден регрессионный тест остановки очистки и блокировки изменений истории. Сохранённый флаг прежней автоматической очистки игнорируется и удаляется из настроек. Проверяются CSRF, актуальность списка, выбор одной копии, изменение файла после просмотра и сохранение переносимой описи.

## Повторная загрузка одинаковых оригиналов

Одинаковый синтетический сценарий: 24 файла по 32 КиБ, 20 потоков, тестовый API, создание ZIP и очистка выключены. Один прогон на вариант, поэтому время не является статистической оценкой производительности сети. Содержимое всех 24 результатов проверено по SHA-256.

| Показатель | Защита выключена | Защита включена |
|---|---:|---:|
| Загрузки оригинала | 24 | 1 |
| Получено содержимого | 768 КиБ | 32 КиБ |
| Сохранено содержимого | 768 КиБ | 32 КиБ |
| Физические копии | 24 | 1 |
| Время вместе с обходом | 1,651 с | 0,556 с |

Проверка имён, размеров и дат не заменяет сравнение содержимого. Очистка отдельно перечитывает копии перед переносом в корзину. История и отчёты содержат путь оставшейся общей копии. Потребление RAM и физический дисковый ввод-вывод в этом опыте отдельно не измерялись.

## Ограничения

Не проверены конкретные аккаунты Яндекс.Диска, реальные NAS, отключение питания, массовая загрузка по интернету с 20 потоками и установка CMD-версии на чистом другом ПК. Синтетические проверки не подтверждают отсутствие всех возможных ошибок.
