# Управление из терминала

CLI управляет той же программой и той же историей, что браузер. Загрузка выполняется отдельным процессом: после `start` терминал можно закрыть.

**CLI доступен только в Linux.** В Windows используйте EXE, в macOS — приложение из DMG.

## Установка в Linux

Установите Python 3.11 или новее. В терминале перейдите в папку проекта и выполните:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
yadisk start
yadisk connect
yadisk open
```

Если в Linux создание окружения недоступно, установите пакет `python3-venv` для своего дистрибутива. После повторного открытия терминала снова выполните `. .venv/bin/activate`.

Для запуска браузерного интерфейса напрямую в Linux можно использовать `sh start.sh`. Такой запуск связан с терминалом: для фоновой работы используйте `yadisk start`.

Готовый консольный файл `yadisk` из нативной сборки выполняет те же команды: `./yadisk start`, `./yadisk connect`, `./yadisk open`. Он должен быть собран для Linux и вашей архитектуры.

## Основные команды

В примерах ниже `yadisk` означает установленную команду Linux.

| Команда | Действие |
| --- | --- |
| `yadisk start` | Запустить приложение в фоне; повторный вызов использует работающий экземпляр |
| `yadisk connect` | Подключить ключ через скрытый ввод |
| `yadisk disconnect` | Отключить ключ |
| `yadisk open` | Открыть браузерный интерфейс |
| `yadisk jobs` | Показать недавние задания и их номера |
| `yadisk status ID --watch` | Смотреть состояние выбранного задания |
| `yadisk plan ID` | Показать план скачивания и имеющиеся копии |
| `yadisk pause ID` | Поставить задание на паузу |
| `yadisk resume ID` | Продолжить задание |
| `yadisk scan ID` | Продолжить прерванную подготовку списка без начала скачивания |
| `yadisk retry ID` | Повторить неудачные файлы и попытаться получить недостающие оригиналы |
| `yadisk limits ID --workers 8 --speed 10` | Изменить число потоков и общий лимит скорости в МБ/с |
| `yadisk stop ID` | Остановить задание с сохранением прогресса |
| `yadisk stop` | Безопасно закрыть всё приложение |
| `yadisk doctor` | Получить результат фоновой проверки приложения; если `busy=true`, повторить команду позже |

Закрытие просмотра `status --watch` через Ctrl+C не останавливает скачивание. `stop` без номера задания останавливает программу для всех её интерфейсов.

## Создать загрузку

```text
yadisk download "disk:/Фото" --to "полный путь к папке" --mode fallback
```

Программа подготовит список и вернёт номер задания. Проверьте `yadisk plan ID`, затем выполните `yadisk resume ID`.

`--run` сразу добавляет подготовку и скачивание в очередь. Можно закрыть терминал после ответа. `--missing` включает дозагрузку в существующую папку. Режимы: `fallback` — оригинал с превью при неудаче, `previews` — превью, `both` — обе копии.

В примере замените пояснение реальным путём. Относительный путь в `--to` отсчитывается от текущей папки терминала и передаётся приложению как абсолютный.

## Для скриптов

`--json` возвращает JSON. Код завершения 0 означает успешную команду, 2 — ошибку команды или связи; результат самой загрузки проверяйте по состоянию задания. Наличие номера задания не означает, что файлы уже скачаны.

`connect --stdin` читает ключ из стандартного ввода. Используйте его только с доверенным источником секрета. Не записывайте ключ в сценарии и не передавайте его аргументом.

`--port` и `--state-dir` позволяют выбрать другой экземпляр. Для всех команд используйте одну пару этих параметров. Проверяется идентификатор папки истории, чтобы не управлять приложением с другой историей по ошибке.

## Что сохраняется после закрытия

Закрытие терминала или браузера не останавливает фоновый процесс. Выключение устройства, перезагрузка и выход из учётной записи — отдельные события; сохранность фонового процесса после выхода из сеанса зависит от ОС. После перезапуска приложения подключите ключ заново и продолжите задание. Ключ автоматически на диск не сохраняется. Расписание не запускает выключенную программу.


Если фоновый запуск завершился с ошибкой, выполните `yadisk start --foreground`: сообщения запуска останутся в терминале. Это диагностический запуск в текущем окне; для обычной фоновой работы `--foreground` не нужен.


### Трафик и завершение текущих файлов

`yadisk traffic` показывает расход. `yadisk traffic --limit-mb 1024` задаёт дневной лимит, `--limit-mb 0` снимает его. `yadisk finish ID` завершает текущие файлы и останавливает задание.

У `download` доступны `--economy`, `--early` и `--verification-workers 1`, `2` или `4`. Ранний старт работает вместе с `--run` и только для новой загрузки. Эти команды доступны в Linux.
