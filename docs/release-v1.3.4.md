# YaDiskDownloader 1.3.4

Продолжение загрузок стало понятнее, а управление — надёжнее.

- Исправлено состояние, в котором прерванная задача оставалась без доступного продолжения. Сохранённые задания можно снова запустить из истории.
- Пауза прерывает зависший сетевой запрос. После продолжения запрос повторяется без расхода дополнительной попытки; пригодные части файла сохраняются.
- При докачке можно выбрать, достаточно ли уже сохранённого превью или нужно попытаться получить оригинал. Сначала скачиваются файлы без копий.
- Перед продолжением проверяется папка с результатами. Готовые оригиналы не скачиваются повторно; изменившиеся файлы проверяются отдельно.
- Неудачная проверка нового ключа больше не сбрасывает прежнее подключение. Запоздалый ответ на старый запрос не отключает новый ключ.
- Ошибки объясняют, где возникла проблема: связь со страницей, ответ Яндекс.Диска, доступ к файлу или запись на ПК. Для внутренних ошибок указан номер обращения.
- Обновлены названия кнопок, подсказки и инструкция. Добавлены быстрые действия для подключения Диска, проверки связи и открытия папки с результатами.
- Остановка незавершённых файлов больше не превращает прогресс в 100%.

**Для Windows:** скачайте `YaDiskDownloader-v1.3.4-Windows-x64.zip`, распакуйте полностью и запустите `YaDiskDownloader.exe`.

**Запуск через CMD:** архив `YaDiskDownloader-v1.3.4-Windows-CMD.zip`, затем `start.cmd`. Для этого варианта нужен Python.

История и профили сохраняются. Ключ доступа хранится в памяти: после полного перезапуска программы подключите его снова. Обычное обновление страницы ключ не удаляет. Превью фото — уменьшенная копия, превью видео — изображение, а не видеофайл.
