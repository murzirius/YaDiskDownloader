# YaDiskDownloader 1.3.4

Обновление снижает нагрузку на ПК и делает интерфейс отзывчивее при больших загрузках.

## Что изменилось

- Уменьшена нагрузка на процессор при скачивании множества файлов.
- Ускорен пересчёт статистики больших списков файлов, сокращены лишние обращения к истории.
- Интерфейс больше не перерисовывает одинаковые данные. Скрытая вкладка делает меньше фоновых запросов и обновляет состояние при возвращении.
- Уменьшена фоновая работа очереди и уведомлений, когда задания не выполняются.
- Сохранена совместимость подсчёта прогресса со старыми записями истории.

Проверка файлов, сохранение прогресса и продолжение недокачанных частей сохранены. Ускорение работы программы не отменяет ограничений и сбоев со стороны Яндекс.Диска.

## Что скачать (одно из двух)

- **[YaDiskDownloader-v1.3.4-Windows-x64.zip](https://github.com/murzirius/YaDiskDownloader/releases/download/v1.3.4/YaDiskDownloader-v1.3.4-Windows-x64.zip)** — готовое приложение для Windows. Распакуйте архив и откройте `YaDiskDownloader.exe`. Python не нужен.
- **[YaDiskDownloader-v1.3.4-Windows-CMD.zip](https://github.com/murzirius/YaDiskDownloader/releases/download/v1.3.4/YaDiskDownloader-v1.3.4-Windows-CMD.zip)** — запуск через `start.cmd`. Нужен Python 3.11 или новее; при первом запуске зависимости устанавливаются автоматически.

История, профили и скачанные файлы сохраняются при обновлении. После полного выхода из программы ключ доступа нужно подключить снова.

Программа продолжает развиваться. Если что-то не работает, [сообщите об ошибке](https://github.com/murzirius/YaDiskDownloader/issues/new).
