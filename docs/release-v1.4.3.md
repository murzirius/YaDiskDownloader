# YaDiskDownloader 1.4.3

Быстрее подготовка дозагрузки больших папок, особенно на сетевых накопителях.

## Что исправлено

- Убраны многократные обращения к файлам при переносе служебных сведений. Названия, результаты проверок и записи описи больше не вызывают отдельную проверку одного и того же пути.
- Подготовка показывает число файлов, а не сумму записей разных таблиц. Логи и отчёты не открываются как скачанный контент.
- Убраны лишние запросы к базе для оригиналов без превью и обращения к недоступным старым папкам при поиске текущей загрузки.
- Прерванная дозагрузка использует ту переносимую опись, которая была выбрана при создании задания. Исправлено её открытие на Windows с Python 3.11 и кодирование путей сетевых папок.
- Исправлены единицы прогресса проверки и подсказка о занятом месте. Эти изменения работают в браузере и в окне EXE.

Проверки содержимого, защита от перезаписи чужих файлов, докачка частей и отчёт об изменениях сохранены. Совпадение имени и размера не считается доказательством целостности. Переносимая опись с другого ПК не разрешает пропускать проверку содержимого.

## Что скачать (одно из двух)

- **YaDiskDownloader-v1.4.3-Windows-x64.zip** — готовое приложение Windows 10/11 x64. Распакуйте архив и откройте `YaDiskDownloader.exe`. Python не нужен.
- **YaDiskDownloader-v1.4.3-Windows-CMD.zip** — запуск через `start.cmd`; требуется Python 3.11 или новее.

Перед обновлением остановите задание, дождитесь остановки и нажмите «Выход». Распакуйте новую версию в отдельную папку. Для дозагрузки выберите прежнюю папку результатов; удалять скачанные файлы и опись не нужно.

Если ошибка повторяется, [сообщите о ней](https://github.com/murzirius/YaDiskDownloader/issues/new).
