# Проверки версии 1.5.0

## Методика сравнения обхода

Сравнение с 1.4.3 (коммит `ed84c89`) на одном Windows-устройстве: Python 3.14.8, SQLite 3.51.3, Pillow 13.0.0. В каждом сценарии 10 000 файлов, три последовательных повтора каждой версии; ниже медианы. HTTP проверяется через настоящий TCP-сервер Waitress. Метаданные имитируются локальным API с указанной задержкой. Это измерение накладных расходов и обхода, а не скорости реального аккаунта Яндекса.

Логический ввод-вывод процесса включает SQLite и не равен физической записи на накопитель. Измерения зависят от нагрузки ОС. Новые индексы очереди и ограниченная параллельная выборка увеличивают часть записей и память; выигрыш — меньше чтений и ожидания API. Задержка HTTP p95 выросла в этих коротких измерениях, но осталась ниже 17 мс. Заявления о снижении всех ресурсов одновременно нет.

Изменения: не более четырёх одновременных страниц, до 1000 объектов на страницу, последовательная фиксация прогресса, вставка локальных имён без двух предварительных SELECT на каждый компонент, индекс очереди по приоритету. Проверки результатов и безопасность путей сохранены.

## Что проверялось

- Полный локальный прогон: 550 тестов прошли, один пропущен. После последних небольших изменений отдельный прогон новых функций, тем, очереди и SQLite: 59 тестов прошли.
- Регрессии: повторяющиеся страницы и пути API, пауза и остановка, восстановление после завершения процесса, дозагрузка, существующие файлы, приоритеты, изменение ограничений, фильтр дат, подсчёт вложенных папок, смена ключа, безопасный журнал SQLite.
- Интерфейс проверен через браузер: 8 из 8 тестовых оригиналов сохранены без ошибок, очередь с будущим временем не начала загрузку, удаление из очереди восстановило кнопку. Проверены размеры и даты папок, пустая папка, темы, экраны шириной 1440 и 390 пикселей.
- Windows: запуск настоящих GUI и CLI EXE, мини-окно, трей, закрытие через интерфейс, освобождение порта и процессов. CLI после завершения запускающего процесса продолжает отвечать и отдавать ресурсы интерфейса. Отдельные проверки ошибок БД и восстановления истории выполняются собранным EXE.
- Аудит полного набора зависимостей: 18 пакетов, известных уязвимостей не обнаружено на момент проверки. Pillow обновлена до 13.0.0; изображения открываются только через разрешённые декодеры. Такой аудит не доказывает отсутствие всех уязвимостей приложения.
- Настоящие консольные сборки Linux x64 и macOS arm64/x64 успешно запущены в [GitHub Actions](https://github.com/murzirius/YaDiskDownloader/actions/runs/39642208568). Проверены отделение фонового процесса, повторное подключение CLI, ресурсы веб-интерфейса и полный выход. Общие тесты Windows, Linux и macOS на Python 3.11 и 3.14 запускаются отдельно; результат последней ревизии доступен в Actions.

## Ограничения проверки

Реальный аккаунт Яндекс.Диска, многосуточная загрузка, настоящий обрыв NAS, macOS/Linux с графическим выбором папки и системной корзиной локально не проверялись. Для них необходимы отдельные испытания. Нативные сборки macOS не подписаны и не заверены Apple. Мини-окно и трей остаются функциями Windows; другие ОС используют браузер и CLI. Смена/выход учётной записи и перезагрузка ОС не равны закрытию терминала: ключ хранится только в памяти и вводится заново после перезапуска приложения.

## Дополнительная проверка macOS и установки CLI

Обнаружена и исправлена задержка прерывания сетевого чтения на Darwin: после shutdown дескриптор активного буферизованного читателя освобождается владельцем ответа. Принудительное закрытие, применяемое в Windows, сохранено для Windows.

На macOS сценарий с двумя параллельными HTTP-загрузками после восстановления сети повторён в отдельном и полном наборах на Python 3.11 и 3.14. Повторные запросы в проверках поступают менее чем за три секунды. Локально после изменения прошли 83 сетевых и связанных регрессионных теста. Эти проверки не заменяют испытание настоящего аккаунта Яндекса.

Python wheel успешно собран, установлен в отдельную папку, CLI запущен из установленного пакета. Архивы Windows содержат проверенные GUI и CLI EXE сборки 20261021.2. Проверены выход через мини-окно/трей/HTTP, освобождение порта и процессов, ресурсы интерфейса, диагностика БД и восстановление истории с 1000 проверенными файлами.
