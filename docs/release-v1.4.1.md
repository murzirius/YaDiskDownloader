# YaDiskDownloader 1.4.1

Быстрее проверка прежней загрузки, компактнее окно Windows и проще выбор папки.

## Что изменилось

- При дозагрузке проверяются скачанные оригиналы и превью из описи. Подсчёт объёма больше не обходит папки с журналами, отчётами и посторонними файлами.
- Старые журналы не перечитываются для подтверждения права на обновление. Используется результат прежней проверки с надёжными признаками изменения файла. Если таких данных нет или файл изменён, он сохраняется, а новый журнал получает отдельное имя.
- Окно EXE стало небольшим экраном состояния: запуск, текущее или последнее задание и прогресс. Загрузки, ключ доступа, история и настройки доступны по кнопке «Открыть в браузере».
- Текст и кнопки окна подстраиваются под масштаб монитора; включена поддержка высокого DPI.
- Кнопка «…» сразу открывает системный выбор папки Windows. Недоступный сетевой путь не проверяется перед показом окна.
- Обновлены подсказки и инструкция.

## Что скачать (одно из двух)

- **YaDiskDownloader-v1.4.1-Windows-x64.zip** — готовое приложение Windows 10/11 x64. Распакуйте и откройте `YaDiskDownloader.exe`. Python не нужен.
- **YaDiskDownloader-v1.4.1-Windows-CMD.zip** — запуск через `start.cmd` с установленным Python 3.11 или новее.

Перед обновлением остановите работу, дождитесь остановки и завершите программу через «Выход». Распакуйте новую версию в отдельную папку. Для дозагрузки выберите прежнюю папку результатов. После полного выхода ключ нужно подключить снова.

Если возникла ошибка, [сообщите о ней](https://github.com/murzirius/YaDiskDownloader/issues/new).
