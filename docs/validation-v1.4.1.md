# Проверки YaDiskDownloader 1.4.1

Windows x64, Python 3.14.8, SQLite 3.51.3. Проверки выполнены в отдельных временных папках с искусственным API и тестовыми файлами.

## Проверка прежней загрузки

Одинаковый локальный сценарий: 4 скачанных файла, 2 000 старых HTML-журналов и журнал размером около 32 МиБ. Это отдельный замер, а не обещание скорости на любом накопителе.

| Показатель | До | После |
| --- | ---: | ---: |
| Время подготовки и обновления статистики | 2,283 с | 0,623 с |
| Прочитано содержимого прежнего журнала | 64,05 МиБ | 0 |
| Объектов при обходе каталога старых журналов | 2 000 | 0 |
| Запросов размера старых журналов | 2 000 | 0 |

Содержимое четырёх скачанных файлов осталось неизменным. Отдельные регрессии проверяют отказ от обхода папок, сохранение изменённого журнала, отсутствие повторной загрузки, подсчёт общей копии один раз и прямой вызов системного диалога из кнопки выбора папки.

## Регрессии и готовый EXE

- 457 тестов пройдено, один пропущен. Новые проверки включают восстановление DPI-контекста потока после закрытия диалога Windows.
- Готовый EXE 20261019.2 реально запущен. Проверены HTTP, актуальные встроенные файлы интерфейса, SQLite, прерванная история, ожидание очереди и завершение через HTTP, трей и мини-окно. Процессы завершаются, порт и блокировка состояния освобождаются.
- В настоящем мини-окне автоматическая проверка подтвердила статус прерванного задания, три кнопки, отсутствие полей ключа и настроек, режим PerMonitorV2.
- Скомпилированные модули проекта сопоставлены с текущим кодом; в именах исходников внутри них нет личных путей компьютера.
- Окно из исходников и нативный диалог выбора папки проверены визуально. Отмена выбора не меняет путь назначения.

## Ограничения проверки

Готовый EXE проверен автоматически; повторная визуальная проверка его финального окна не завершена. Физические мониторы с масштабом 150–200%, перенос между такими мониторами, реальный аккаунт Яндекс.Диска и сетевой NAS в этом прогоне не проверялись.

На файловой системе без надёжных признаков изменения старый служебный файл сохраняется, а новый получает другое имя: непроверенный журнал не перезаписывается.
