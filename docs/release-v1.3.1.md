# YaDiskDownloader 1.3.1 — управление заданиями и исправления

## Что изменилось

- **До 8 потоков.** Максимум ограничен восемью; старые задания и профили с большим значением автоматически приводятся к этому пределу.
- **Остановка обхода.** Обход можно остановить, сохранить найденное и продолжить позже. «Продолжить обход» возвращает к оценке; скачивание запускается отдельной кнопкой.
- **Удобнее управление.** Кнопки работы подняты над статистикой, добавлены подсказки, панель текущего задания и заметная кнопка «Выход».
- **Исправлен выход из трея.** Меню не ждёт блокировку рабочего задания. При выходе отменяются сетевые запросы и останавливается сервер; зависшие фоновые потоки больше не удерживают процесс бесконечно.
- **Проверка папки перед дозагрузкой.** Программа проверяет уже сохранённые файлы до начала скачивания и обновляет прогресс. Подтверждённые оригиналы повторно не скачиваются; повреждённые и отсутствующие файлы возвращаются в очередь.
- **Приоритет недостающих файлов.** Сначала загружаются файлы без результата, затем программа пытается получить оригиналы для файлов только с превью. Поддерживается перенос папки с другого компьютера.
- **Более точная оценка времени.** Для оригиналов учитывается устойчивая передача данных, для превью и повторов — фактическое время полных циклов обработки файлов с учётом параллельности. Размеры оригиналов не делятся на скорость маленьких превью или оборванных попыток.
- **Понятное состояние при сбоях.** При серии неудач или отсутствии передачи вместо необоснованных десятков дней показывается причина уточнения оценки. Паузы и ожидание интернета исключены; ZIP оценивается отдельно.
- **Альтернативный запуск через CMD.** Добавлен отдельный архив с `start.cmd`. Нужен обычный Python 3.11 или новее; зависимости устанавливаются автоматически при первом запуске.
- **Обновлённая подпись статистики.** Занимаемое место отображается как «На устройстве».
- **Исправления автоматических проверок Windows.** Улучшены очистка фоновых заданий, ожидания на медленных дисках и проверка восстановления сети.

## Какую сборку скачать

- **YaDiskDownloader-v1.3.1-Windows-x64.zip** — готовый EXE, Python не требуется.
- **YaDiskDownloader-v1.3.1-Windows-CMD.zip** — запуск через `start.cmd`, требуется Python 3.11+.
- **YaDiskDownloader-v1.3.1-source.zip** — полные исходники.
- **SHA256SUMS-v1.3.1.txt** — контрольные суммы архивов.

## Обновление

Завершите программу через «Выход» в интерфейсе или трее, распакуйте новую сборку и запустите её. История и профили сохраняются; токен нужно ввести заново.

Оставшееся время является приблизительной оценкой и зависит от доступности файлов и скорости сервиса.
