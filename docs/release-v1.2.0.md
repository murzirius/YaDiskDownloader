# YaDiskDownloader 1.2.0 — EXE для Windows и стабильная загрузка

Готовая сборка для Windows, новые средства управления загрузкой и исправления для больших импортов.

## Новое

- **EXE для Windows:** запуск без установки Python, интерфейс открывается в браузере.
- **Значок в трее:** открытие интерфейса, пауза, продолжение и завершение приложения. Загрузка продолжается после закрытия браузера.
- **Исключения папок и файлов:** точные пути и шаблоны; исключённые папки не обходятся.
- **Объём по папкам:** количество файлов, размер оригиналов и учёт неизвестных размеров.
- **Отчёт об изменениях:** новые, изменённые и исчезнувшие источники в отдельном HTML-отчёте. Локальные копии не удаляются.
- **Ограничение скорости:** общий лимит в МиБ/с для всех потоков; 0 — без ограничения.
- **Сообщение об ошибке:** подготовка описания с версией, ОС и статистикой для формы GitHub, с просмотром перед отправкой.
- **Восстановление после обрыва сети:** предупреждение о потере связи, сохранение частей и автоматическое продолжение после восстановления доступа. Ожидание связи не расходует попытки; зависшие соединения открываются заново.
- **Перенос истории при обновлении:** общая папка состояния для исходников и EXE, автоматический импорт прежних задач и профилей из найденной старой установки.

## Исправления

- Ускорена подготовка после обхода: пакетная работа с SQLite, меньше повторных проверок и отдельный индикатор подготовки.
- Дозагрузка учитывает уже сохранённые файлы. Для проверенного оригинала превью повторно не скачивается; первыми обрабатываются файлы без сохранённого результата.
- Успешный оригинал или превью считается результатом. Неудача другого варианта остаётся в журнале и не засоряет список ошибок.
- Статистика показывает полный объём папки на ПК, включая прежние файлы, ZIP, отчёты и части загрузок.
- Умные потоки временно отключены. Используется заданное число потоков; параметры по умолчанию: **8 потоков, 1 попытка, 20 секунд на попытку**.

## Установка и обновление

**Windows 10/11 x64:** скачайте `YaDiskDownloader-v1.2.0-Windows-x64.zip`, полностью распакуйте и запустите `YaDiskDownloader.exe`. Python не требуется. Инструкция по подключению Диска доступна в интерфейсе. Сборка не подписана цифровой подписью.

Перед обновлением завершите приложение через трей. История и профили сохраняются в `%LOCALAPPDATA%\YaDiskDownloader`; после перезапуска подключите Диск заново. При первом переходе со старой установки обновите файлы в прежней папке или распакуйте новую рядом, чтобы программа нашла старую `.state`. Результаты остаются в выбранных папках.

**Исходники:** `YaDiskDownloader-v1.2.0-source.zip`, Python 3.11+ и `start.cmd`.

Программа работает только на локальном ПК, читает Яндекс.Диск и не удаляет файлы в облаке. Сообщения об ошибках не отправляются автоматически.
