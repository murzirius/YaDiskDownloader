# YaDiskDownloader 1.3.2 — восстановление и исправления Windows

- Уменьшены лишние операции SQLite во время обхода и скачивания. База сохраняет каждую транзакцию с полной синхронизацией; защита подтверждённых результатов при сбое остаётся включённой.
- Файлы для свободных потоков назначаются одной короткой транзакцией. Порядок приоритетов дозагрузки сохраняется, максимум — 8 потоков.
- Исправлена нестабильная проверка восстановления после аварийного завершения на медленных дисках Windows. Проверяется вся очередь из 451 файла, их содержимое и отчёт; ожидание остаётся ограниченным.
- В логи автоматических проверок добавлены номер версии, коммит, версии Python и SQLite и предел потоков, чтобы было видно, какой код проверялся.
- Включены улучшения управления из предыдущей сборки: остановка и продолжение обхода, подсказки, панель текущего задания и исправленный выход через трей.

## Скачать

- **YaDiskDownloader-v1.3.2-Windows-x64.zip** — готовое приложение Windows x64, Python не требуется.
- **YaDiskDownloader-v1.3.2-Windows-CMD.zip** — запуск через `start.cmd`, нужен обычный Python 3.11+.
- **YaDiskDownloader-v1.3.2-source.zip** — полные исходники.
- **SHA256SUMS-v1.3.2.txt** — контрольные суммы архивов.

## Обновление

Завершите старую программу, распакуйте новую сборку и запустите её. История и профили сохраняются, токен вводится заново. Не запускайте старый и новый экземпляры одновременно с общей папкой состояния.
