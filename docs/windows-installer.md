# Установщик для Windows

Начиная с версии 1.5.2 рядом с `YaDiskDownloader-v<версия>-Windows-x64.zip` публикуется
`YaDiskDownloader-v<версия>-Windows-x64-Setup.exe`. Оба файла собираются из одного набора
файлов, поэтому содержат одинаковую программу, лицензии и исходники зависимостей.

## Установка

1. Скачайте Setup.exe из [Releases](https://github.com/murzirius/YaDiskDownloader/releases).
2. Запустите его. **Права администратора не нужны**: программа ставится для текущего пользователя
   в `%LOCALAPPDATA%\Programs\YaDiskDownloader`. Папку можно изменить в мастере.
3. В мастере можно отметить ярлык на рабочем столе. Ярлык в меню «Пуск» создаётся всегда.
4. На последней странице можно сразу запустить программу.

Автозапуск вместе с Windows не настраивается. Ключ доступа к Яндекс.Диску по-прежнему вводится заново
после каждого перезапуска программы.

### Предупреждение SmartScreen

Установщик и EXE **не имеют цифровой подписи** (сертификата нет). При первом запуске Windows может
показать синее окно «Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**.
Скачивайте файл только со страницы релизов этого репозитория и при желании сверьте SHA-256
(показывается GitHub рядом с файлом) командой `Get-FileHash .\YaDiskDownloader-…-Setup.exe`.

## Обновление

- **Из программы** («Установить и перезапустить» в окне версии) — как и раньше: заменяется только EXE.
  Автообновление использует ZIP-файл релиза; Setup.exe для него не нужен.
- **Новым Setup.exe** — запустите его поверх: файлы заменяются, история и настройки не затрагиваются.
  Если программа открыта, установщик предложит её закрыть.

Кнопка «Установить» в окне версии у ZIP-версии не перезапишет установку, сделанную через Setup.exe, —
она сообщит об этом и ничего не изменит.

## Удаление

«Параметры Windows → Приложения → YaDiskDownloader → Удалить» (или `unins000.exe` в папке программы).
Удаляются программа, ярлыки и служебные файлы. В конце спрашивается, удалять ли **историю и настройки**
(`%LOCALAPPDATA%\YaDiskDownloader`). Ответ по умолчанию — «Нет». **Скачанные файлы
(`Загрузки\YaDiskDownloader`) не удаляются никогда.** Тихое удаление (`/VERYSILENT`) сохраняет историю,
если не передан параметр `/DeleteHistory=yes`.

## Сборка

Нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`).

```bash
python build_windows.py --output dist/windows --work build/windows
python -m pip download --no-deps --dest dist/windows/third_party pystray==0.19.5
python tools/package_release.py --exe dist/windows/YaDiskDownloader.exe --output dist/release
python tools/build_installer.py --output dist/release
```

Сценарий — `installer/YaDiskDownloader.iss`. В GitHub Actions (`checks.yml`, задача `windows_exe`) установщик
собирается после ZIP, проверяется `tests/test_windows_installer.py` (установка, обновление поверх
изменённого EXE, удаление с сохранением истории) и вместе с ZIP загружается в релиз по тегу `v*`.
Тест пропускается, если Inno Setup не найден или на ПК уже стоит настоящая установка.
