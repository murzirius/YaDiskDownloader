# Понятный прогресс чтения истории

На этапе «Читаем историю скачанной папки» приложение переносит сведения прежней загрузки. Счётчик складывал строки списка файлов, имён, результатов и проверок. Для одного файла существует несколько записей, поэтому число записей истории может превышать количество скачанных файлов.

Интерфейс ошибочно показывал на этом этапе «Ищем файлы…», «Найдено файлов: 0», неопределённый индикатор и кнопку «Остановить обход». По этим подписям было невозможно понять, что программа ещё читает историю, прежде чем начнёт новый обход и проверку копий.

Исправлено:

- Перед переносом подсчитывается конечное число записей именно в выбранном источнике истории.
- Показаны записи истории, общий предел, процент и тип переносимых сведений.
- Этап и обе кнопки остановки подписаны как чтение истории и остановка подготовки.
- Указано, что записи истории не равны количеству файлов; повторный обход и проверка копий следуют после переноса.
- Пакеты по 200 записей, проверки локальных путей, доверие к контрольным данным и возможность остановки сохранены.

Проверены собственная история приложения и переносимая опись в папке: конечный счётчик, остановка после частичного переноса, повторное продолжение без дублирования и сохранность файлов. В отдельном браузерном опыте с 55 готовыми файлами показано 226 записей истории; старый интерфейс выводил бы их как неопределённое количество объектов. Остановка проверяется также через HTTP-интерфейс настоящего локального сервера.

Исправление относится к индикации прогресса. Скорость работы с NAS не измерялась: время чтения и проверки путей на сетевом хранилище зависит от SMB, накопителя и Windows. Проверки выполнены на локальных тестовых данных.

Итоговые проверки Windows, Python 3.14.8: **413 passed, 1 skipped за 178,32 с**; пропуск связан с правами на символические ссылки Windows. JavaScript проходит node --check. После остановки и продолжения через браузер задание дошло до «Список готов»; SHA-256 всех 55 тестовых файлов совпадает. CMD-архив проверен на целостность, содержит 61 файл и соответствует исходникам; пользовательская история и виртуальное окружение в него не включены. Чистая установка через start.cmd на другом ПК не проверялась.

## Проверка готового EXE

Windows EXE собран из коммита 56242fa и действительно запущен. В отдельном опыте без ключа Яндекса через локальное сохранение описи выполнен перенос истории: 1000 тестовых файлов, конечный предел 3002 записи, получено 46 снимков прогресса. Перенос и сохранение описи завершились; SHA-256 всех 1000 файлов совпадает. Опыт занял 4,138 с вместе с запуском приложения. Это локальные тестовые данные, а не замер NAS или полной дозагрузки из облака.

Дополнительно проверены актуальность всех встроенных файлов интерфейса, история прерванной работы, ожидание очереди, выбор папки, CSRF, выход через HTTP и нативное закрытие трея. Оба процесса завершились, дочерние процессы и порт освобождены. Запуск 2,79–3,26 с, завершение 2,46–3,04 с; встроенная SQLite 3.51.3. Windows-архив проверен на целостность и содержит тот же EXE, который запускался в этих проверках. Новый GitHub Release не создавался.
