# Понятный прогресс чтения истории

На этапе «Читаем историю скачанной папки» приложение переносит сведения прежней загрузки. Счётчик складывал строки списка файлов, имён, результатов и проверок. Для одного файла существует несколько записей. Поэтому значение 86 тысяч записей само по себе не означает 86 тысяч скачанных файлов или бесконечный обход.

Интерфейс ошибочно показывал на этом этапе «Ищем файлы…», «Найдено файлов: 0», неопределённый индикатор и кнопку «Остановить обход». По этим подписям было невозможно понять, что программа ещё читает историю, прежде чем начнёт новый обход и проверку копий.

Исправлено:

- Перед переносом подсчитывается конечное число записей именно в выбранном источнике истории.
- Показаны записи истории, общий предел, процент и тип переносимых сведений.
- Этап и обе кнопки остановки подписаны как чтение истории и остановка подготовки.
- Указано, что записи истории не равны количеству файлов; повторный обход и проверка копий следуют после переноса.
- Пакеты по 200 записей, проверки локальных путей, доверие к контрольным данным и возможность остановки сохранены.

Проверены собственная история приложения и переносимая опись в папке: конечный счётчик, остановка после частичного переноса, повторное продолжение без дублирования и сохранность файлов. В отдельном браузерном опыте с 55 готовыми файлами показано 226 записей истории; старый интерфейс выводил бы их как неопределённое количество объектов. Остановка проверяется также через HTTP-интерфейс настоящего локального сервера.

Это исправление индикации, а не подтверждённое ускорение NAS. На сетевом хранилище время чтения и проверки путей зависит от SMB, накопителя и Windows. Состояние конкретного пользовательского NAS по фотографии определить нельзя; бесконечный цикл на нём не воспроизведён. Пользовательские файлы на сетевом хранилище в ходе этой проверки не читались и не изменялись.

Итоговые проверки Windows, Python 3.14.8: **413 passed, 1 skipped за 178,32 с**; пропуск связан с правами на символические ссылки Windows. JavaScript проходит node --check. После остановки и продолжения через браузер задание дошло до «Список готов»; SHA-256 всех 55 тестовых файлов совпадает. CMD-архив проверен на целостность, содержит 61 файл и соответствует исходникам; пользовательская история и виртуальное окружение в него не включены. Чистая установка через start.cmd на другом ПК и новый EXE в рамках этого изменения не проверялись.
