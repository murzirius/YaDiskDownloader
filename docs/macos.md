# Установка на Mac

Скачайте образ `.dmg` для своего Mac:

- **arm64** — Mac с процессором Apple M1, M2, M3, M4 или новее.
- **x64** — Mac с процессором Intel.

Процессор указан в меню ** → Об этом Mac**. Необходима macOS 13 или новее. Сборки проверяются на macOS 15; старые версии отдельно не проверялись.

1. Откройте скачанный `.dmg`.
2. Перетащите **YaDiskDownloader** на ярлык **Applications («Программы»)** рядом с ним.
3. Извлеките образ диска и откройте **YaDiskDownloader** из «Программ».
4. Дождитесь запуска. Интерфейс откроется в браузере; подключите ключ Яндекс.Диска.

Python и терминал не нужны. В небольшом окне есть кнопки **«Открыть интерфейс»** и **«Выход»**. Закрытие окна и браузера не останавливает загрузки. Нажмите значок программы в Dock, чтобы снова открыть окно. **«Выход»** сохраняет прогресс и завершает работу приложения; также можно нажать **⌘Q**.

## Если macOS не разрешает открыть приложение

Предварительная сборка имеет техническую подпись, но **не имеет сертификата Developer ID и не заверена Apple**. Поэтому Gatekeeper может показать предупреждение. Если доверяете источнику загрузки, откройте **«Системные настройки → Конфиденциальность и безопасность»** и разрешите открытие этого приложения. Не отключайте защиту macOS целиком.

Если сообщения об открытии нет в настройках, проверьте, что выбрана сборка для вашего процессора и приложение перенесено в «Программы». При другой ошибке приложите её текст к [сообщению о проблеме](https://github.com/murzirius/YaDiskDownloader/issues/new).

## Обновление и удаление

Для обновления нажмите **«Выход»**, дождитесь завершения и замените приложение в «Программах». История и профили находятся отдельно, в `~/Library/Application Support/YaDiskDownloader`; ключ хранится только в памяти и после запуска вводится заново. Скачанные файлы остаются в выбранной папке.

Для удаления завершите работу и перенесите приложение из «Программ» в Корзину. Это не удаляет историю и скачанные файлы. Автоматическая установка обновлений из интерфейса пока доступна только в Windows.

Заданиями и настройками управляйте в браузере. CLI доступен только в Linux.
