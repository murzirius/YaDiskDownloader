# Возможности 1.5.0

## Список файлов и папок

Нажмите **«Посчитать папки»** над списком. Подсчёт идёт в фоне; его можно остановить. Программа читает метаданные файлов на Яндекс.Диске, а не скачивает фотографии для подсчёта.

- Размер папки — сумма размеров файлов во всех вложенных папках. Единицы выбираются автоматически: Б, МиБ, ГиБ или ТиБ.
- Дата папки — самая поздняя дата изменения вложенного файла. Дата самой папки не используется.
- До подсчёта размер и дата неизвестны. Пустая папка имеет размер 0 и пометку «Нет файлов».
- «≥» означает, что часть размеров неизвестна или часть папки прочитать не удалось. Показанная дата также относится только к прочитанным файлам.
- Результат относится к моменту подсчёта. После изменений запустите подсчёт снова. Переключение аккаунта не показывает результаты прежнего аккаунта.

Фото, видео, музыка, документы, таблицы, презентации, PDF, архивы, код, программы и прочие файлы имеют SVG-иконки. Их качество не зависит от масштаба интерфейса.

## Оформление

В **«Оформлении»** доступны Really Black, Dracula, Nord, Catppuccin Mocha и Latte, Tokyo Night, Everforest, Solarized Light и Dark, Gruvbox, High Contrast и базовые светлая и тёмная темы. Можно изменить размер текста и акцентный цвет, включить компактный список или переключение темы вслед за системой. Собственные темы JSON по-прежнему поддерживаются; исполняемые стили и скрипты не принимаются.

Используются адаптации палитр [Dracula](https://draculatheme.com/spec), [Nord](https://www.nordtheme.com), [Catppuccin](https://github.com/catppuccin/catppuccin), [Tokyo Night](https://github.com/folke/tokyonight.nvim), [Everforest](https://github.com/sainnhe/everforest), [Solarized](https://ethanschoonover.com/solarized/) и [Gruvbox](https://github.com/morhetz/gruvbox). Названия обозначают цветовую схему; это самостоятельный интерфейс приложения.

## Дополнительные параметры

Нажмите **«Показать все параметры»**, чтобы открыть фильтр дат, приоритет папок, расписание и остальные ограничения.

Фильтр дат использует изменение, создание или дату съёмки, если она передана Яндекс.Диском. По умолчанию файлы без выбранной даты включаются: так фотографии не пропадут из выбора из-за отсутствующих метаданных. Окончание периода включается целиком.

Приоритетные пути указываются по одному на строку. Сначала скачиваются файлы без какой-либо сохранённой копии, а внутри этой группы — приоритетные папки. Выбор приоритета сам по себе не добавляет папку в источник задания.

В карточке задания раскройте **«Изменить скорость и потоки»**. Новые ограничения применяются без остановки. При уменьшении потоков текущие файлы завершаются, а новые запускаются в пределах нового лимита. Скорость 0 означает отсутствие ограничения.

## Расписание и питание

Время запуска задаётся до создания задания. После подготовки добавьте задание **«В очередь»**. Оно начнётся после предыдущих заданий и наступления выбранного времени, если приложение работает, очередь включена и ключ подключён. Кнопка запуска в браузере добавляет будущее задание в очередь. Прямое продолжение через CLI в Linux позволяет начать раньше.

Тихие часы задают отдельную скорость и отключают обычные уведомления о результате. Часы используются по местному времени устройства; одинаковое начало и окончание означают весь день.

Опция **«Не давать устройству заснуть»** использует системный запрет автоматического сна. Она не включает выключенный компьютер и не предотвращает ручное выключение. Запрет снимается при паузе и после работы. Если ОС не разрешила запрет сна, в журнале появится объяснение, а загрузка продолжится.

## Результат и проверка

В **«Найти файл в задании»** видны сохранённые копии, ошибки и причины пропусков. Исключённая папка показывается как исключение целиком: её вложенные файлы ради этого списка не обходятся.

**«Проверить новые и изменённые файлы»** создаёт новый обход прежнего выбора в ту же папку. После него можно посмотреть изменения и начать дозагрузку. Это полезно, если на Диск добавлялись файлы во время долгого скачивания.

**«Проверить приложение»** выполняет быструю проверку истории и её накопителя в фоне. Наличие подключённого ключа само по себе не доказывает доступность всех файлов Яндекс.Диска.

График собирается, пока он открыт на видимой странице. Он хранит до пяти минут наблюдения в памяти вкладки. Закрытие графика не влияет на работу задания.

## Windows, macOS и Linux

Общий интерфейс работает в браузере. Windows EXE сохраняет мини-окно и трей. На macOS используется приложение из DMG и браузер; в Linux доступны браузер и CLI; Windows-мини-окно и автоматическая установка обновления EXE не переносятся на другие ОС.

В macOS выбор папки использует системный диалог. В Linux нужен `zenity` или `kdialog` и графический сеанс; без них полный путь можно ввести вручную. Корзина зависит от ОС и накопителя. Неудача перемещения в корзину не заменяется безвозвратным удалением.

Папка истории по умолчанию: `%LOCALAPPDATA%/YaDiskDownloader` в Windows, `~/Library/Application Support/YaDiskDownloader` в macOS, `$XDG_STATE_HOME/YaDiskDownloader` либо `~/.local/state/YaDiskDownloader` в Linux. Скачанные файлы сохраняются в выбранное место.

CLI для Linux описан в [отдельной инструкции](cli.md). Для обновления не удаляйте прежнюю папку результатов, переносимую опись и историю.

На macOS и Linux с SQLite без исправления WAL используется журнал DELETE с полной синхронизацией записи. Уязвимый режим WAL не включается. Сборки Windows требуют SQLite с исправлением.
