# YaDiskDownloader 1.3.3

Исправления запуска Windows и новые проверки сохранности загрузки.

- Исправлен сбой запуска и выхода при неподходящей кодировке консоли Windows.
- Устранено голодание потоков при параллельной записи истории на медленном диске. Записи SQLite выполняются по очереди; защита сохранения FULL остаётся включённой.
- В EXE обновлена SQLite до 3.51.3: исправлена редкая ошибка записи истории в режиме WAL. Сборка со старой библиотекой теперь запрещена. При запуске исходников со старой SQLite используется безопасный журнал DELETE.
- Для больших файлов разделены два ограничения: ожидание без новых данных и время всей попытки. Новая загрузка ждёт данные 20 секунд; общий предел выключен. Ранее сохранённые задания и профили сохраняют свой общий предел.
- Итоги показывают полные оригиналы, файлы только с превью и файлы без результата. Успешное превью не считается ошибкой файла, но и не выдаётся за сохранённый оригинал.
- Автоматическая проверка теперь запускает собранный EXE, проверяет интерфейс, SQLite, значок в трее и полное завершение процессов. Публикация сборки разрешена только после успешных проверок.
- Добавлен длительный нагрузочный тест: большой список файлов, имитация обрывов связи и медленной записи, принудительное завершение процесса, продолжение и проверка SHA-256 каждого файла. Результаты и измерения сохраняются в JSON.
- Обновлены GitHub Actions, добавлены подробные результаты тестов и ограниченные ожидания на медленных Windows runners.

## Скачать

- **YaDiskDownloader-v1.3.3-Windows-x64.zip** — обычный запуск на Windows, Python не нужен. Распакуйте архив и откройте `YaDiskDownloader.exe`.
- **YaDiskDownloader-v1.3.3-Windows-CMD.zip** — запуск через `start.cmd`, нужен обычный Python 3.11 или новее.
- **YaDiskDownloader-v1.3.3-source.zip** — исходный код.
- **SHA256SUMS-v1.3.3.txt** — контрольные суммы архивов.

История, профили и скачанные файлы сохраняются при обновлении. Яндекс может ограничивать выдачу оригиналов; программа не может обойти эти ограничения. Ошибки можно сообщить [здесь](https://github.com/murzirius/YaDiskDownloader/issues/new).
