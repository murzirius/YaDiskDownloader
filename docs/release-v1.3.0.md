# YaDiskDownloader 1.3.0 — сохранение прогресса и управление загрузками

- Ручной выбор до 20 потоков; начальные параметры остаются 8 потоков, 1 попытка, 20 секунд.
- Отчёты, журнал и отчёт об изменениях обновляются под постоянными именами. Дозагрузка в ту же папку сохраняет результаты и события прежних задач.
- Усилено сохранение прогресса: SQLite с полной синхронизацией, запись намерения перед публикацией файла и восстановление прерванной публикации по контрольной сумме. На Windows используются операции переименования с принудительной записью.
- Добавлены история с поиском, названиями, архивом и страницами, а также сохраняемая очередь заданий.
- Локальная проверка ранее скачанной папки работает без интернета и показывает отсутствующие или повреждённые копии.
- Резервные копии истории и профилей: автоматическая копия перед обновлением базы, ручное создание, экспорт, импорт и восстановление.
- Очистка зарегистрированных устаревших временных файлов через корзину Windows. Пригодные части и папки активных задач защищены.
- Проверенное обновление Windows EXE из интерфейса с резервной копией и откатом при неудачном запуске.
- Закрываемые сообщения интерфейса, системные уведомления Windows и собственное оформление элементов управления.
- GitHub Actions проверяет код и готовит Windows EXE, исходники и контрольные суммы для тега версии после успешных тестов.

## Установка

Windows 10/11 x64: полностью распакуйте `YaDiskDownloader-v1.3.0-Windows-x64.zip` и запустите `YaDiskDownloader.exe`. Python не требуется. Сборка не подписана цифровой подписью.

Для запуска через Python используйте `YaDiskDownloader-v1.3.0-source.zip`, Python 3.11+ и `start.cmd`.

## Обновление

При переходе с 1.2.1 завершите приложение через трей, замените EXE новой сборкой и запустите его. История и профили сохранятся; токен потребуется ввести заново. Обновление из интерфейса доступно для последующих переходов с версии 1.3.0.

Очередь после восстановления истории приостановлена. Сначала подключите Диск и проверьте задания. История и её резервные копии содержат личные пути и предназначены для локального хранения; архив диагностики остаётся отдельным обезличенным файлом.

Контрольные суммы: `SHA256SUMS-v1.3.0.txt`. Подробное использование: `docs/usage.md`.
