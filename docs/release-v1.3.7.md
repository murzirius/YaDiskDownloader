# YaDiskDownloader 1.3.7

Обновление исправляет учёт сохранённых файлов, ускоряет проверку папки на устройстве и упрощает запуск загрузки.

## Что изменилось

- Главный экран предлагает скачать файлы, продолжить загрузку, проверить папку или открыть историю. Настройка новой загрузки разделена на три шага.
- Перед запуском проверяются папка назначения, возможность записи и свободное место. Сложные параметры доступны в дополнительных настройках.
- Проверка готовых файлов делает меньше обращений к SQLite. Проверки целостности и обнаружение изменённых файлов сохранены.
- Подготовка прежней истории и восстановление файлов после сбоя выполняются в фоне. Интерфейс показывает текущий этап.
- Временная ошибка Яндекс.Диска больше не убирает готовые файлы из учёта.
- Офлайн-проверка учитывает файлы, которые ещё не скачались. Дозагрузка использует весь проверенный выбор, независимо от количества страниц проблем.
- Исправлены повторный запуск задания очередью, поиск русских названий и устаревшие ошибки в отчёте.
- После загрузки и создания ZIP выполняется итоговая сверка размера папки. Она не блокирует интерфейс.
- После обновления объёма папки учитываются файлы, удалённые вручную.
- Ошибки сохранения описи и недоступная папка показываются явно. Опись можно сохранить повторно.
- При обновлении списка ошибок сохраняется фокус клавиатуры. Добавлены подсказки и понятные действия для продолжения.

## Что скачать (одно из двух)

- **YaDiskDownloader-v1.3.7-Windows-x64.zip** — готовая программа для Windows. Распакуйте архив и откройте `YaDiskDownloader.exe`. Python не нужен.
- **YaDiskDownloader-v1.3.7-Windows-CMD.zip** — запуск через `start.cmd`. Нужен Python 3.11 или новее.

История, профили и скачанные файлы сохраняются. После полного выхода из программы ключ доступа нужно подключить снова.

Сбои и ограничения Яндекс.Диска могут влиять на загрузку. Если программа работает неправильно, [сообщите об ошибке](https://github.com/murzirius/YaDiskDownloader/issues/new).
