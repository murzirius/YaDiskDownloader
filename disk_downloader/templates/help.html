Шаг 1 из 3

Создай приложение Яндекса

  1. Войди в аккаунт, с которого хочешь скачивать файлы, и открой Яндекс OAuth → Создать приложение.
  2. Выбери тип «Для доступа к API или отладки».
  3. Название сервиса: Disk Downloader. Контактная почта: твоя почта.
  4. В доступах найди Яндекс Диск и выбери только «Чтение всего Диска» — cloud_api:disk.read. Создай приложение.

Для этого типа приложения Redirect URI уже задан: https://oauth.yandex.ru/verification_code. Платформу, права записи, удаления и данные профиля добавлять не требуется.

Официальная инструкция по регистрации

Получи OAuth-токен

  1. На странице созданного приложения скопируй ClientID / Client_ID. Это идентификатор приложения, не секрет и не токен.
  2. Вставь его ниже и открой страницу получения токена. Проверь аккаунт и подтверди доступ к чтению Диска.
  3. Скопируй выданный OAuth-токен, вернись сюда и вставь его в поле сверху. Нажми «Подключить».
Открыть получение токена

Client_secret не нужен. Если страница показывает токен в адресе, возьми значение после access_token= до следующего &. Токен вводится только в локальном интерфейсе, хранится в памяти и после перезапуска вводится снова.

Официальная инструкция по получению токена

Выбери файлы и начни загрузку

  1. Отметь нужные папки или включи «Скачать весь Диск». Общие папки других пользователей тоже попадут в этот выбор.
  2. Выбери папку на ПК, типы файлов и режим. Превью скачиваются для фото и видео, музыка и другие файлы — оригиналами.
  3. Нажми «Оценить выбранное», дождись обхода и нажми «Начать».
  4. Для повторного обхода выбери «Дозагрузить недостающее» и прежнюю папку Disk-…. До начала скачивания программа проверяет локальную папку и учитывает найденные оригиналы в прогрессе. Сначала загружаются файлы без результата, затем программа пробует заменить превью оригиналами. Проверенный оригинал исключает новую загрузку превью.

По умолчанию: 8 потоков, 1 попытка, 20 секунд на попытку. ZIP и отчёты сохраняются прямо в папке импорта. Кнопка ZIP открывает эту папку.
