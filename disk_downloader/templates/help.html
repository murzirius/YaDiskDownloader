Давай подключим твой Диск

Шаг 1 из 3

1. Разреши программе читать файлы

Для этого создай запись в настройках Яндекса. Она понадобится только один раз.

  1. Открой страницу Яндекса. Войди в аккаунт, с которого хочешь скачать файлы.
  2. Если появится выбор, нажми «Для доступа к API или отладки».
  3. В поле названия напиши Disk Downloader, а в поле почты — свой адрес.
  4. В доступах отметь «Чтение всего Диска» (cloud_api:disk.read). Нажми «Создать приложение».

Что должно получиться: открылась страница созданного приложения. Оставь её открытой и нажми «Далее» здесь.

Если спрашивают другие настройки

Для выбранного типа Redirect URI уже задан: https://oauth.yandex.ru/verification_code. Доступа к чтению Диска достаточно; остальные разрешения оставь выключенными.

Подсказка Яндекса

2. Получи ключ доступа

  1. На странице созданного приложения найди ClientID / Client_ID. Скопируй эту строку из 32 символов и вставь в поле ниже.
  2. Нажми «Открыть получение токена». На странице Яндекса проверь аккаунт и разреши доступ.
  3. Скопируй выданный токен — это ключ доступа к файлам. Вернись сюда и нажми «Далее».
Открыть получение токена

Кнопка не работает? Проверь, что скопировал весь ClientID без пробелов. Client_secret не нужен.

Где искать токен, если его нет на странице?

Посмотри адрес страницы Яндекса. Скопируй только значение после access_token= и до следующего &.

Подсказка Яндекса

Токен похож на пароль: не отправляй его другим людям. После перезапуска программы его нужно вставить снова.

3. Подключись и выбери файлы

  1. Нажми «Начать работу» внизу. Сверху в программе вставь токен в поле OAuth-токен и нажми «Подключить».
  2. Когда появятся файлы, поставь галочки у нужных папок. Или включи «Скачать весь Диск», чтобы выбрать всё, включая общие папки.
  3. В поле «Сохранить в» нажми … и выбери папку на компьютере.
  4. Выбери режим. «Только превью» сохраняет уменьшенные копии фото и видео. Для полных файлов выбери режим с оригиналом. Музыка и другие файлы скачиваются целиком.
  5. Нажми «Оценить выбранное». Дождись надписи «Оценка готова» и нажми «Начать скачивание».

Где результат? В выбранной папке появится папка Disk-…. Настройки уже готовы: 8 загрузок одновременно, 1 попытка, 20 секунд без новых данных.

Как продолжить прошлую загрузку?

Выбери «Как загрузить → Дозагрузить недостающее» и укажи прежнюю папку Disk-…. Программа сначала проверит, что уже есть. После оценки нажми «Начать скачивание».

Чтобы закрыть программу, нажми «Выход» сверху. Закрытая вкладка браузера оставляет загрузку работающей.
